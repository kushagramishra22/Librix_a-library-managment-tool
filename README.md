Librix: A QR-Based Library Management Tool
Librix is an innovative web-based library management application that leverages QR code technology to simplify and automate book and user management. Designed for both librarians and patrons, Librix ensures efficient tracking of resources, seamless borrowing operations, and an organized catalog system.

Key Features
QR Code Integration:

Each book entry is assigned a unique QR code, ensuring accurate tracking of individual books and quantities.
Users can scan QR codes to borrow, return, or check details of books, streamlining library operations.
Dynamic Book Management:

Easily add, update, and delete books.
Manage multiple copies of the same title with precise quantity tracking.
User Management:

Admins can create and manage user accounts.
Users can view their borrowing history and stay updated with due dates.
Efficient Borrowing and Returning System:

QR-based borrowing and return workflows eliminate manual errors.
Automated tracking of overdue books with fine calculation (if applicable).
Advanced Search Functionality:

Locate books by title, author, genre, or ISBN with ease.
QR code scanning provides instant access to specific book details.
Responsive Design:

Fully accessible on desktops, tablets, and mobile devices for enhanced usability.
